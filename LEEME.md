# Complementos López

Abre **index.html** con doble clic en el Explorador de archivos. La web funciona directamente desde la carpeta, sin instalar dependencias ni arrancar un servidor. Mantén juntos los archivos HTML, el CSS, el JavaScript y las carpetas de recursos, artículos y proyectos.

En **Soluciones**, elige un tipo de negocio para ver su propuesta. Los tres proyectos del sitio son casos ficticios de demostración. Las cuatro lecturas del cuaderno tienen sus propias páginas.

En **Contacto**, elige una necesidad, escribe tu idea y añade tus datos de contacto si quieres. Pulsa **Generar mi resumen** para revisar la ficha y **Descargar mi resumen** para guardarla como texto. El enlace **Buscar en el mapa** abre Google Maps y requiere conexión a Internet.

Las imágenes de la sección **Servidores** ilustran el montaje propuesto de Mac mini. Se generaron con ImageGen, igual que las dos escenas de **Equipo** y la imagen de bocetos del **Cuaderno**.

Si prefieres probar la web con un servidor local y tienes Python instalado, abre PowerShell en esta carpeta y ejecuta:

```powershell
py -m http.server 8080 --bind 127.0.0.1
```

Abre http://127.0.0.1:8080 en tu navegador. Pulsa Ctrl+C en la consola para detener el servidor.
