PROGRAMACIÓN 2 min DE LECTURA

Programar con oficio.

El código sostiene el recorrido que el diseño propone. Queremos que el cliente pueda leer, elegir y actuar incluso con un móvil antiguo o una conexión intermitente.

01 / CUADERNO DEL ESTUDIO

Empezar por el contenido

Usamos títulos con jerarquía, enlaces para navegar y botones para las acciones. Un formulario necesita etiquetas visibles y mensajes que expliquen cómo corregir cada campo. Probamos todo con teclado antes de darlo por bueno.

02 / CUADERNO DEL ESTUDIO

Cuidar el peso de cada página

Ajustamos las imágenes a su tamaño de uso y dejamos que las que quedan más abajo carguen al acercarse. Antes de sumar una librería, comprobamos si una función del navegador cubre la misma necesidad.

03 / CUADERNO DEL ESTUDIO

Probar el recorrido y sus fallos

Si la web pide una cita, probamos el camino completo, incluidos los campos vacíos y la pérdida de conexión. Un mensaje de éxito solo aparece cuando el sistema confirma que ha recibido la solicitud.

Una prueba para tu web

Prueba el recorrido principal usando solo Tab, Mayús + Tab y Enter. El foco debe verse y seguir el orden de lectura.
