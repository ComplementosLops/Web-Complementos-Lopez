ALOJAMIENTO 2 min DE LECTURA

Publicar con un plan.

Publicar implica mover la web a un entorno que pueda usar cualquiera. Reservamos tiempo para probar el cambio y para saber cómo volver a la versión anterior si hace falta.

01 / CUADERNO DEL ESTUDIO

Preparar el cambio

Inventariamos el dominio, sus redirecciones y los registros que ya usa el correo. Hacemos una copia de la versión vigente, comprobamos cómo restaurarla y elegimos una franja tranquila para publicar.

02 / CUADERNO DEL ESTUDIO

Comprobar desde fuera

Una vez visible, entramos con un móvil por datos y abrimos las direcciones principales. Revisamos que HTTPS funciona, que las rutas antiguas importantes llevan al lugar correcto y que la web puede completar sus acciones.

03 / CUADERNO DEL ESTUDIO

Dejar responsables y señales claras

Anotamos quién puede intervenir y dónde revisar errores. Vigilamos la respuesta del servidor y las acciones importantes, como el envío de un formulario, durante los primeros días.
