MANTENIMIENTO 2 min DE LECTURA

Cuidar la web cada mes.

Una web cambia con el negocio. La atención mensual combina el trabajo técnico con una revisión de lo que realmente está leyendo y usando la gente.

01 / CUADERNO DEL ESTUDIO

Revisar lo que caduca

Repasamos horarios, precios y promociones. También abrimos enlaces y descargables desde un móvil para comprobar que siguen llevando al documento o destino correcto.

02 / CUADERNO DEL ESTUDIO

Actualizar y poder volver atrás

Revisamos los componentes instalados, guardamos una copia y probamos los cambios antes de aplicarlos al sitio público. De vez en cuando restauramos una copia en un entorno de pruebas para verificar que sirve.

03 / CUADERNO DEL ESTUDIO

Medir una tarea concreta

Elegimos una tarea del negocio, como consultar la carta o solicitar una cita. La recorremos de principio a fin y apuntamos dónde puede atascarse una persona, incluso si el servidor responde correctamente.

Una prueba para tu web

Cada vez que cambie el horario del local, comprueba la portada, la página de contacto y los perfiles donde también lo publicas.
